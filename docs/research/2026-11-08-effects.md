# Firelink effect attribution — 8 November 2026

Private source-frame controls separate the scene's low foreground haze from the earlier
distant mist draw. Two late alpha-blended draws add the foreground contribution; two later
draws using the same textures make no further colour change in this captured frame. The
control maps HDR stage snapshots through the checked source tone curve with fixed captured
bloom. It does not regenerate exposure, temporal history or bloom after removing an effect.

Both observed texture payloads match entries read from the source install. Binary reference
searches identify candidates, then the existing private SoulsFormatsNEXT reader exposes

## Native billboard and shading controls

An authored billboard now passes independent effect, texture and map readback and renders

property; the independent contract rejected that fixture. The revised identifier survives
serialization. A separate placement check also rejected a build that omitted the runtime
coordinate rebase before it was launched. The accepted fixture reaches a native tessellated
billboard draw with the expected texture payload and alpha blending.

A frozen diagnostic reads one captured source frame's particle state. It preserves the two
textures, including every mip, and writes the captured positions, dimensions, rotations,
atlas frames and opacity. It is a shading control, not an emitter translation. File readback
checks all 76 particles. An initial GPU count check wrongly required every particle to draw
in one camera view. An independent projection and polygon-clipping check finds exactly 16
intersecting octagons; all 16 reach the GPU. Their positions agree within 0.02 millimetres,
and their rotated basis components within two millionths. The failed count check is retained.

The first frozen build quantizes faint opacity through native byte colour. A revised build
uses the independent floating-point colour multiplier; its field contract rejects the first
build, then passes the revision. A fresh background capture verifies the source opacity on
all 16 visible particles, with geometry unchanged. Both capture runs exit through the normal
UI. This establishes static billboard writing, not emission timing, random distribution or
motion.

The remaining weak haze has several causes in the native shading path: colour decoding and
a draw colour reduction differ, the default soft-depth span is shorter, and the source's
camera-distance fade and atmospheric terms are absent. An independent calculation matches
608 captured source vertex outputs for fog, atmospheric filtering and scattering, depth
span, and opacity. An earlier calculation incorrectly excluded near-plane crossings; the
corrected calculation includes the captured crossing behaviour.

Replay controls isolate colour reduction, source colour response, and the combined source
response. Changing colour alone overshoots because it retains the native depth fade and
omits the source atmosphere. The combined control produces a subtle foreground contribution
closer in magnitude to the captured source contribution. This is attribution, not a full
image-equivalence score: the scene inputs differ, and the visualization holds bloom fixed.

Two controls caught errors in the replay implementation. The native shader is shared with
other effects, so replacement must be restricted to the selected particles. Also, identical
shader bytes can have separate live resource identities; replacing just one left one
billboard variant unmodified and produced coloured haze. The corrected replay replaces both
instances and guards their captured bindings. Independent readback of 144 generated native
vertices then matches the source atmospheric expressions and distance fade. Its first
projection calculation omitted native temporal jitter; using the actual captured projection
fixes that discrepancy without relaxing the tolerance.

These reconstructed programs, captured values, reports and images remain private. The replay
still uses frozen particles, one daylight view and the first snapshot's byte opacity. Native
near-plane handling and tessellator interpolation have not been shown equivalent to the
source in general. The next seam is a build-local shader selection that isolates translated
particles without capture-specific descriptor indices, followed by live source emitter
translation and multi-view motion checks. No production dependency or ordinary playtest
promotion follows from these controls.

A private normal-camera forward/backward walk also passed, with about 4.9 metres of measured
movement, a lossless recording and normal exit. It is a narrow movement check, not evidence
