# Firelink effect attribution — 8 November 2026

Private source-frame controls separate the scene's low foreground haze from the earlier
distant mist draw. Two late alpha-blended draws add the foreground contribution; two later
draws using the same textures make no further colour change in this captured frame. The
control maps HDR stage snapshots through the checked source tone curve with fixed captured
bloom. It does not regenerate exposure, temporal history or bloom after removing an effect.

Both observed texture payloads match entries read from the source install. Binary reference
searches identify candidates, then the existing private SoulsFormatsNEXT reader exposes
explicit texture references in the matching source effect. The map places that effect at two
regions in Firelink. Its definition includes billboard clusters, an animated texture atlas,
emission volumes and colour/opacity timelines. This is evidence for translating an omitted
placed effect; it does not justify increasing every surface's brightness.

The source effect reader and surveys stay outside the repository under the existing local
game-data permission. SoulsFormatsNEXT retains its previously recorded GPL-3.0 licence.

For a private host-writing trial, [EvenTorset/fxr](https://github.com/EvenTorset/fxr) provides
typed emitters, particle attributes and billboard actions, and declares Elden Ring output
support. Its [licence](https://github.com/EvenTorset/fxr/blob/main/LICENSE) is the Unlicense.
The trial may use this library and its format metadata locally; neither is added to this
repository or selected as a production dependency. The generated effect must be checked
through the independent existing reader and in the running host before claiming support.
Source interpolation, randomization and native shading differences remain to be measured.
